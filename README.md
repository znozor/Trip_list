# WeatherTrip ⛅

WeatherTrip is a smart travel packing list generator that helps travelers pack based on destination weather forecasts and trip duration.

## Features

- 🌦️ Weather-based packing suggestions
- 🧳 Smart travel checklist generation
- 📍 Destination trip planning
- 📱 Mobile-friendly design
- 🔐 Google Sign-In support
- 📝 Save and manage trips
